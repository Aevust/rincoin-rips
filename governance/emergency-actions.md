# Rincoin Core — Emergency Action Log

**Last Updated**: 2026-06-07

This file records every invocation of the emergency exception defined in RIP-0001 §Change Submission Discipline and Emergency Exception — that is, any direct commit to the official Rincoin Core repository that bypassed the normal pull-request review path to mitigate an actively exploited or imminently exploitable defect.

This log does NOT cover role transitions (see `editor-changes.md`) or routine changes (which proceed through standard pull-request review and are recorded in repository commit history).

Each entry MUST document: the date, the actor(s) who invoked the exception, the defect mitigated, the exact scope of the direct commit, the retroactive pull request opened within 72 hours, and the disclosure made to node operators.
